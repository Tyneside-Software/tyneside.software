## Grok export — easiest paths

Grok’s UI changes; any of these work:

| Method | How |
|--------|-----|
| **A. Select-all paste** | Open the Grok chat → select the thread (or the useful stretch) → copy → paste into a new `.txt` / `.md` in `inbox-drops` |
| **B. Share / export if shown** | If Grok offers **Share**, **Export**, or **Copy conversation**, use that → save as `.txt` or `.md` into the dump folder |
| **C. Partial dumps** | Only the good bits — paste under a heading `## Grok — topic` in one running file: `inbox-drops/running-grok.md` |

**Prefer plain text or Markdown.** HTML exports are fine but messier.

No need to clean. Dobby sorts into `material/01…20/` later.
