Status machine (summary)

requested
  → quoted            (optional; skip for fixed-price packs)
  → confirmed
  → assigned
  → en_route
  → on_site           (in_progress label OK in UI)
  → completed
  → cancelled | no_show | failed

Every transition → job_event (actor, timestamp, optional note).
